1. What is the difference between getElementById, getElementsByClassName, and querySelector / querySelectorAll?
getElementById for id only.
getElementsByClassName for class name only.
querySelector for id and class both but we have to use css selector.
querySelectorAll for specific all id and all class for same element.

2. How do you create and insert a new element into the DOM?
Using ".createElement" attribute.

3. What is Event Bubbling? And how does it work?
If I set event handler in parents section and If I set event handler in sister section under same section then If I click on sister area then both event showing results.

4. What is Event Delegation in JavaScript? Why is it useful?
Set event handler in parent element and handle child elements.
This is useful because of we no need to set event handler to many times by using event delegation.

5. What is the difference between preventDefault() and stopPropagation() methods?
preventDefault() need for stopping default behavior of browser and stopPropagation() need to stop bubbling the events.
